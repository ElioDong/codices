General objective

To build a small-scale digital library that describes six illuminated manuscripts with standardised metadata and makes them available to anyone, on any device, without depending on proprietary technologies.

Specific, measurable objectives

Objectives and verification criteria
No. Objective How it is verified
O1 Describe six manuscripts with metadata conforming to Dublin Core Every record passes schema validation; the fifteen elements are present or justifiably absent
O2 Publish the site live by the deadline Reachable URL, communicated to the lecturer at least one day before the exam
O3 Achieve WCAG 2.1 AA conformance Automated check with axe DevTools with no errors; manual keyboard check
O4 Work without JavaScript With JavaScript disabled, all content remains readable
O5 Load in under 2 seconds on a simulated 4G network Measurements with Lighthouse on the collection page

What the project does not do

Defining the scope is part of the work. The following remain outside it: the actual digitisation of authentic copies, optical character recognition (OCR) on transcriptions, full-text search, user authentication, and any form of online editorial collaboration.

Licence and reuse

The descriptive content and the sample images are released under a Creative Commons BY 4.0 licence: anyone may reuse them, including commercially, provided the source is cited.

The HTML and CSS code is released under the MIT licence. This dual licensing is deliberate: data and code raise different issues and deserve different legal instruments. Data should circulate as widely as possible; code should be reusable even within projects with different licences.
