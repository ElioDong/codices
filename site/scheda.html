Why fifteen elements and no more

Dublin Core is deliberately minimal: it is the subset of description on which any institution can converge. The finer data — collation, watermarks, graphic variants — live in the TEI transcription, which is rich but not interoperable at the same level. The strategy is: Dublin Core to be found, TEI to be understood.

Elements used

  • <msDesc> — structured codicological description
  • <lb/> — line break in the witness
  • <abbr> — abbreviation, with expansion in square brackets
  • <pb/> — change of folio

Why not HTML alone

In HTML one could write the same thing with <p> and <br>, but the meaning would be lost: a machine would not be able to distinguish a line break in the manuscript from a typographic line break. TEI serves to say what that text is, not merely how it is to be displayed.
